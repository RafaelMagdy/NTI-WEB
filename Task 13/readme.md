What entity you chose and why ??
---
I had chose the entity book entity because it has more small informations that can be objects which make the add,delete,search,update actions more easier.

Routes summary
---

- POST/books: Creates a new book record in the database using the data provided in the request body.

- GET/books: Retrieves a list of all books from the database.

- GET/books/:id: Fetches a single book record by its unique ID.

- PATCH/books/:id: Updates an existing book record based on its ID with the new data from the request body.

- DELETE/books/:id: Deletes a book record from the database using its ID.

How to run your code locally
